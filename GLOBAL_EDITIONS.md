## Multilingual Executive Summaries

### English
*Beyond the Prompt* presents a rigorous systems architecture for production autonomous AI agents, replacing ad-hoc prompt chaining with bounded statecharts, deterministic context engineering, and formal verification harnesses. Companion reference kernels, an AST harness auditor, and the Interactive Attention Sandbox provide reproducible patterns for GraphRAG, Model Context Protocol (MCP) orchestration, and fault-tolerant execution loops.

### 简体中文 (Simplified Chinese)
